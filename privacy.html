Politique de confidentialité

Sendit pour Google Sheets

Dernière mise à jour : 10 décembre 2024

1. Introduction

Cette politique de confidentialité décrit comment l'add-on "Sendit pour Google Sheets" collecte, utilise et protège vos données personnelles.

2. Données collectées

L'add-on collecte uniquement les données nécessaires à son fonctionnement :

  • Clés API Sendit : Public Key et Secret Key pour l'authentification avec l'API Sendit
  • Ville de ramassage : ID de votre ville de ramassage configurée
  • Données de feuille de calcul : Les informations de livraison que vous saisissez dans votre Google Sheet

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Authentifier votre compte Sendit via l'API
  • Créer des livraisons sur la plateforme Sendit
  • Synchroniser les statuts de vos livraisons
  • Générer des étiquettes de livraison

4. Stockage des données

Les données sont stockées de manière sécurisée :

  • Clés API : Stockées dans PropertiesService de Google (chiffré, accessible uniquement par vous)
  • Tokens d'authentification : Mis en cache temporairement (1 heure) dans CacheService
  • Données de livraison : Restent dans votre Google Sheet (sous votre contrôle)
  • Cache des villes : Stocké dans une feuille cachée de votre document

Important : Aucune donnée n'est stockée sur des serveurs externes. Tout reste dans votre compte Google.

5. Partage des données

Vos données ne sont jamais partagées avec des tiers, sauf :

  • Avec l'API Sendit (nécessaire pour créer/suivre les livraisons)
  • Avec Google (infrastructure d'hébergement de l'add-on)

Aucune donnée n'est vendue, louée ou partagée à des fins commerciales.

6. Sécurité

Mesures de sécurité en place :

  • Chiffrement des données par Google
  • Communication HTTPS uniquement
  • Tokens d'authentification à durée limitée (1 heure)
  • Pas de stockage en clair des identifiants
  • Isolation des données par utilisateur

7. Vos droits

Vous avez le droit de :

  • Accéder à vos données (disponibles dans votre Google Sheet)
  • Modifier vos données (via la configuration de l'add-on)
  • Supprimer vos données (désinstallez l'add-on ou supprimez les propriétés)
  • Exporter vos données (téléchargez votre Google Sheet)

8. Permissions requises

L'add-on demande les permissions suivantes :

  • spreadsheets.currentonly : Accès au Google Sheet actuel uniquement
  • script.container.ui : Afficher l'interface utilisateur (sidebar, dialogs)
  • script.external_request : Communiquer avec l'API Sendit

9. Cookies et tracking

L'add-on n'utilise pas :

  • Cookies de tracking
  • Outils d'analyse (Google Analytics, etc.)
  • Publicités
  • Tracking comportemental

10. Conformité RGPD

Pour les utilisateurs de l'Union Européenne :

  • Consentement explicite requis lors de l'installation
  • Droit à l'oubli respecté (suppression des données)
  • Droit à la portabilité (export des données)
  • Transparence totale sur l'utilisation des données

11. Modifications de la politique

Nous nous réservons le droit de modifier cette politique de confidentialité. Les modifications seront publiées sur cette page avec une mise à jour de la date.

12. Contact

Pour toute question concernant cette politique de confidentialité :

  • Email : chrittyassine@gmail.com
  • Site web : sendit.ma

13. Suppression des données

Pour supprimer vos données :

  1. Désinstallez l'add-on depuis Google Sheets
  2. Ou contactez-nous à chrittyassine@gmail.com

Vos données seront supprimées immédiatement de nos systèmes (PropertiesService).
