Sendit pour Google Sheets

Besoin d'aide pour installer ou utiliser l'add-on ?

Démarrage

  1. Installez l'add-on depuis le Google Workspace Marketplace.
  2. Ouvrez une feuille Google Sheets → Extensions → Sendit pour Google Sheets → Configurer les clés API.
  3. Créez un compte ou connectez-vous sur app.sendit.ma, puis copiez Public Key et Secret Key.
  4. Chargez les villes, choisissez la ville de ramassage, enregistrez.
  5. Extensions → Créer une feuille modèle, puis créez vos colis.

Problèmes fréquents

  • Impossible de s'authentifier — vérifiez les clés sur app.sendit.ma (Intégration API).
  • Ville introuvable — utilisez le modèle, ou Extensions → Rafraîchir les villes.
  • Téléphone refusé — 10 chiffres commençant par 0, colonne formatée en texte.
  • Le menu n'apparaît pas — rechargez la feuille. Le menu se trouve sous Extensions.
